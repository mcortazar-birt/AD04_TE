# AD04_TE
Versión 1.0 de la tarea Evaluativa
Se utilizan Java 21 y las versiones apropiadas de las dependencias del proyecto.

## Ejecutar el proyecto
Para ejecutar el proyecto, basta con configurar la variable de entorno 'DB_PASSWORD' y cambiar en *src/main/resources/META-INF/persistence.xml* las propiedades de url y user en caso de ser necesario.
